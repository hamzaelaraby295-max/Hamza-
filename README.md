# منصة صانع الرجال | كُن الأَفْضَل

ملفات الرفع المباشرة إلى GitHub:
1. `index.html`: الموقع الكامل (شاشة الدخول والتسجيل، بوابة الدفع والاشتراك الشهري لمدة 30 يوماً بسعر 250 على المحفظة 01273568689، لوحة الإدارة والربط السحابي، مشهد الترحيب ثلاثي الأبعاد Motion Graphics، وصفحات التدريبات والغذاء والأنشطة، وخانة المساعدة والدعم بعد القبول).
2. `README.md`: ملف تعريف المستودع.

## خطوات الرفع إلى GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على GitHub.
2. ارفع ملف `index.html` وملف `README.md` إلى الفرع الرئيسي (`main`).
3. من تبويب **Settings** ثم **Pages**، اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
